# dsh-chat-background

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的聊天区加一段**循环播放的视频背景**：视频可以铺满整个界面、也可以只出现在聊天区域内，永远循环，并且可以**分区域**与视频交融——每个区域独立设置位置、大小、颜色与混合方式，做出渐隐、暗角、上下遮罩等效果。

## 它解决什么问题

普通的「背景图」只能铺一张静态图。本插件把视频作为背景，并允许：

1. **循环播放**指定视频（`mp4`/`webm`/`mov` 等），没有视频时用插件自带的动画背景；
2. **两种背景范围**：全屏（整个界面，含侧栏）或仅聊天区域（视频只在会话区，侧栏等其余区域自动适配同一套派生主题）；
3. **调节视频透明度**、模糊、整体压暗、缩放、播放速度；
4. **背景音频**：可选「视频原声」或「自定义音频文件」（`mp3`/`wav`/`ogg`/`flac`/`m4a` 等），界面右下角有一个浮动播放按钮，可以暂停/继续，浏览器拦截带声音自动播放时点一下就解锁；
5. **主题色**：手动指定一个主题色，或开启「自动主题色」让插件从视频主体颜色推导并平滑跟随；
6. **界面配色自动适配**：文字、输入框、卡片、「新会话」按钮等颜色会从背景画面推导，保证 WCAG 对比度；也可以逐个角色手动指定；
7. **分区域混合**：多个区域各自与视频交融，互不影响，做出有层次感的背景。

## 推荐安装法

本插件是本地开发包，用 `link:` 安装最方便：

```
帮我安装本地插件 <本目录的绝对路径>
安装 spec 用 link:<本目录绝对路径>。
优先用 plugin_manager 工具：action=install_bundle，target 填上面的 spec。
如果没有 plugin_manager，就手动改 profile 的 package.json：
1. profile 目录是 <home>/profiles/<profile 名>，<home> 取 resolveDshHome() 的结果
   （默认 $DSH_HOME，未设置时为 ~/.dsh）；
2. 在 dependencies 里加 "dsh-chat-background": "link:<本目录绝对路径>"，
   并把 "dsh-chat-background" 加进 dsh.profile.bundles；
3. 在该目录里用 DSH 自带的 pnpm 执行 install；
4. 装完告诉我需要重启 DSH，以及设置页在哪儿。
```

DSH 桌面版的实际 profile 目录是 `%APPDATA%\dsh-desktop\harness\profiles\web`（本机上是 `C:\Users\Administrator\.dsh\profiles\desktop`）。

## 普通安装法

把本目录发布成 npm 包后：

```bash
dsh plugin --profile web add dsh-chat-background
```

或者手动改 profile 的 `package.json`，把 `dsh-chat-background` 加进 `dependencies` 和 `dsh.profile.bundles`，然后在该目录执行 `pnpm install`。

装完**重启 DSH** 生效。

## 使用

装好重启后就会播放内置动画背景。

打开 **设置 → 插件 → 聊天背景**：

- **背景范围**：「全屏（整个界面）」或「仅聊天区域」。仅聊天区域时只有中间会话区出现视频背景，容器会跟随布局变化（侧栏拖动、面板折叠都会跟上）。**侧栏、右栏等其余区域不再是原样，而是自动适配同一套派生主题**（v0.8）：它们是不透明面板，插件为其单独推导一套实心配色（面板底、侧栏底、选中会话行、文字、次级文字、按钮、代码块、边框），全部按各自实际底色保证 WCAG 对比度，并随视频逐帧缓动。聊天区的手动选色只影响聊天区，永远不会把侧栏洗白。
- **背景视频**：留空使用内置背景，或点「选择文件…」挑一个视频/动图，也可以直接粘贴路径。
- **透明度 / 模糊 / 压暗 / 缩放 / 速度 / 填充方式**：调节画面本身。
- **背景音频**：「静音 / 视频原声 / 自定义音频」三选一。选自定义时再挑一个音频文件（`mp3`/`wav`/`ogg`/`flac` 等）；自定义文件无效时自动退回视频原声，设置页会提示。音量、循环可调。
- **自动主题色**：勾选后，插件从视频主体颜色推导主题色，并随视频变化平滑跟随。取消勾选则使用下面手动选的颜色。**颜色切换是逐帧渐变的**（v0.7）：采样每 2 秒取一次新目标，显示色按指数缓动（时间常数 0.7s）逐帧逼近——背景色调、文字/气泡/按钮/代码块等全部派生色同步平滑流动，不再两秒一跳；画面静止时动画自动停摆，不耗 CPU。
- **主题色 / 主题色强度 / 主题色混合方式**：手动指定主题色及其作用强度与混合算法。
- **界面配色适配**：多个角色各有一个「自动」开关：文字基色、**用户消息文字**、**模型回复文字**、**用户气泡**、**代码块背景**、**代码块文字**、**行内代码背景/文字**、**按钮背景/文字**（输入框 + 号、回到底部、加载更早等聊天区控件）、强调色（高亮/选中态/链接）、面板（**输入框**/卡片）。自动模式下颜色从背景画面推导并保证对比度（正文 ≥7:1，气泡文字、回复文字、代码文字、按钮文字 ≥4.5:1），取消勾选即可手动选色（初始值即当前画面推导出的实际颜色）。代码块/按钮文字即使手动指定，也会被自动修正到在其背景上可读；手动浅色配手动浅底这种"撞色"组合同样会被拉开对比。「面板不透明度」控制磨砂程度。注意：这些角色只作用于**聊天区**；「仅聊天区域」模式下侧栏等其余区域走独立的自动派生配色（v0.8，不受手动选色影响），设置弹窗与浮层菜单始终豁免。
- **Windows 标题栏透明**（仅全屏作用域）：整条标题栏带随视频透出，拖拽区与窗口按钮不受影响；「仅聊天区域」模式下标题栏保持不透明，与侧栏一致。
- **区域混合**：每个区域独立设置名称、形状（径向/线性）、锚点、大小、强度、颜色、混合方式，以及是否渐变、是否反向。可以添加任意多个区域。

点「保存」生效（下次打开或刷新页面即可，无需重启）。点「清除」则不再播放背景。

背景右下角有一个**浮动音频按钮**（只在音源不是「静音」时出现）：点击可以暂停/继续；当浏览器拦截了带声音的自动播放时按钮会高亮提示，点一下（或任意点击/按键）声音就开。

## 行为

| 状态 | 表现 |
|---|---|
| 视频未设置 | 播放内置动画背景 |
| 视频清空 | 不播放背景，插件完全不介入 |
| 视频设置了路径 | 循环播放该视频。路径无效则不播放，原因显示在设置页 |
| 音频「视频原声」 | 视频自带音轨播放（GIF 等无声素材则无声音） |
| 音频「自定义文件」 | 播放该音频，视频自身音轨静音避免双重声音；文件无效退回视频原声 |
| 音频「静音」 | 无音频按钮，不播放任何声音 |

背景层位于界面之下（`z-index: -1`、`pointer-events: none`），所以**不会挡住任何点击**。插件会把范围内表面的底色改成透明让视频透出，同时把文字、面板、边框的颜色重新推导一遍保证可读性。

### 分层结构

背景由四层组成，从下到上：

```
视频 → 各区域混合层 → 主题色层 → 整体压暗层
```

每个区域是一层独立的渐变，用自己的 `mix-blend-mode` 与视频交融。因为整块背景在一个独立的层叠上下文里，区域的混合只会和它下面的视频/区域作用，**不会污染上面的界面**。

### 退出方式

背景没有「跳过」按钮——它是常驻的。想关闭就在设置页点「清除」，或取消勾选相关设置。

### 仅聊天区域模式是怎么定位的

聊天区没有专门的「背景槽位」，所以 `scope: chat` 时插件会找到承载会话的那一栏（从 `[data-conversation-scroll]` 向上回溯到 shell 框架的直接子元素），用一个 500ms 的轻轮询加窗口 resize 监听跟踪它的位置和大小，把原本铺满视口的固定容器平移成它的矩形。侧栏拖动、面板折叠、窗口缩放都会跟上。找不到聊天栏（例如当前是插件页、自动化任务页）时视频不再上屏（v0.8.2）：整页保持不透明并由派生主题接管，回到会话页后自动恢复。

## 配置

在 profile 的 `cordis.patch.yml` 里写覆盖项即可调整细节（Windows 上通常是 `%APPDATA%\dsh-desktop\harness\profiles\web\cordis.patch.yml`）：

```yaml
- id: dsh-chat-background
  config:
    src: D:/wallpapers/bg.mp4
    scope: chat
    opacity: 0.6
    blur: 4
    dim: 0.5
    themeAuto: true
    themeColor: '#6f86ff'
    themeStrength: 0.35
    audioSource: custom
    audio: D:/music/ambience.mp3
    audioVolume: 0.6
    uiText: auto
    uiUserText: '#ffd54a'
    uiAssistantText: '#9fe8b8'
    uiBubble: '#2b3a66'
    uiCodeBlock: '#0d1117'
    uiCodeText: auto
    uiInlineCode: auto
    uiInlineCodeText: auto
    uiButton: '#ffd54a'
    uiButtonText: auto
    uiAccent: '#8ab4ff'
    uiSurfaceAlpha: 0.5
    regions:
      - id: vignette
        shape: radial
        anchor: { x: 0.5, y: 0.5 }
        size: 1.15
        strength: 0.55
        color: '#000000'
        blend: multiply
        gradient: true
        invert: true
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `src` | 空 | 背景视频路径。空 = 使用内置动画；清空后不再播放 |
| `scope` | `fullscreen` | `fullscreen` 整个界面 / `chat` 仅聊天区域 |
| `opacity` | `0.5` | 视频透明度 0–1 |
| `muted` | `true` | 兼容保留项，声音改由 `audioSource` 决定 |
| `volume` | `0` | 兼容保留项，音频音量改用 `audioVolume` |
| `fit` | `cover` | `cover` 铺满裁切 / `contain` 完整显示 / `fill` 拉伸 |
| `blur` | `0` | 背景模糊像素 0–20 |
| `dim` | `0.45` | 整体压暗 0–1 |
| `scale` | `1` | 缩放 0.5–3 |
| `speed` | `1` | 播放倍速 0.1–3 |
| `themeAuto` | `true` | 从视频主体颜色自动推导主题色 |
| `themeColor` | `#6f86ff` | 主题色（`themeAuto` 开启时被自动值覆盖） |
| `themeStrength` | `0.35` | 主题色强度 0–1 |
| `themeBlend` | `soft-light` | 主题色混合方式 |
| `regions` | 见下 | 区域混合列表。空列表 = 只保留纯视频 |
| `audioSource` | `none` | `none` 静音 / `video` 视频原声 / `custom` 自定义音频文件 |
| `audio` | 空 | 自定义音频路径（`audioSource: custom` 时生效；无效则退回视频原声） |
| `audioVolume` | `0.6` | 背景音频音量 0–1 |
| `audioLoop` | `true` | 自定义音频是否循环（视频原声总是循环） |
| `uiText` | `auto` | 文字基色：`auto` 从画面推导，或 `#rrggbb`。作为下面所有角色的共同回退 |
| `uiUserText` | `auto` | **用户消息文字**颜色。自动时跟随 `uiText`/推导值，并保证在气泡上 ≥4.5:1 |
| `uiAssistantText` | `auto` | **模型回复文字**颜色。自动时跟随 `uiText`/推导值，并保证在画面上 ≥4.5:1 |
| `uiBubble` | `auto` | **用户气泡**背景色。自动时为画面向主题色的柔和偏移 |
| `uiCodeBlock` | `auto` | **代码块背景**颜色（含顶部语言栏）。自动时深色画面取更深的嵌板色、浅色画面取柔和浅灰 |
| `uiCodeText` | `auto` | **代码块文字**颜色。自动时跟随 `uiText`/画面推导，并保证在代码块背景上 ≥4.5:1（语法高亮色不受影响） |
| `uiInlineCode` | `auto` | **行内代码**（正文里的 `code` 小片）背景色。自动时与面板错开一档的嵌片色 |
| `uiInlineCodeText` | `auto` | **行内代码文字**颜色。自动时跟随 `uiText`/画面推导，并保证在行内代码背景上 ≥4.5:1 |
| `uiButton` | `auto` | **按钮族背景**（聊天区）：输入框左下角「添加文件或调用指令」(+)、聊天区「回到底部」圆钮、「加载更早」、主按钮。自动时取与面板同调的实心色，保证两条墨色路径都 ≥4.5:1。「仅聊天区域」下侧栏「新会话」跟随其余区域的派生主题（v0.8），全屏下与其他按钮同组 |
| `uiButtonText` | `auto` | **按钮族文字**。自动时按按钮底色自动取深/浅墨并保证 ≥4.5:1——修掉"白底白字"的原始缺陷 |
| `uiAccent` | `auto` | 强调色：高亮、选中态、链接 |
| `uiSurface` | `auto` | 面板颜色（**输入框**、卡片、弹出层） |
| `uiSurfaceAlpha` | `0.55` | 面板磨砂不透明度 0–1 |

### 区域字段

| 字段 | 默认 | 说明 |
|---|---|---|
| `id` | 自动 | 区域名称，仅用于标识 |
| `shape` | `linear` | `radial` 径向 / `linear` 线性 |
| `anchor` | `{x:0.5,y:0.5}` | 锚点，归一化坐标 0–1 |
| `size` | `0.45` | 大小（渐变范围）0.05–4 |
| `strength` | `0.6` | 强度（不透明度）0–1 |
| `color` | `#000000` | 区域颜色 |
| `blend` | `multiply` | 混合方式：`normal`/`multiply`/`screen`/`overlay`/`soft-light`/`hard-light`/`color-dodge`/`color-burn`/`difference`/`exclusion` |
| `gradient` | `true` | 是否使用平滑渐变（false 则硬边） |
| `invert` | `false` | 径向区域是否反向（中心透明、边缘着色，用于暗角） |

默认包含三个区域：`vignette`（径向暗角）、`top`（顶部遮罩）、`bottom`（底部遮罩），用来保证聊天内容可读。

字段填写有误只会退回默认值，不会导致启动失败。

## 自动主题色与界面配色是怎么工作的

插件每隔 2 秒从视频当前帧采样一次：

1. 把当前帧画到一个 32×32 的离屏画布上；
2. 统计既不是纯黑也不是纯白的像素的平均值，得到一个代表色；
3. 用该颜色更新主题色，每次只向新值缓动 25%，所以颜色会平滑跟随视频变化而不是突然跳变。

界面配色在此基础上再算一步。插件估计「用户实际看到的背景」是什么颜色（代表色按 `dim` 压暗、再按 `themeStrength` 向主题色偏移），然后：

- **文字**：按画面明暗选浅/深基色，再逐步向白或黑插值，直到与背景的 WCAG 对比度达到 7:1；
- **次要文字**：同样保证 ≥ 4.5:1；
- **强调色**：以主题色为源，提升到 ≥ 4.5:1，保证按钮和高亮在背景上看得见；
- **面板**：深色画面配深色面板、浅色画面配浅色面板，并按「面板不透明度」与背景混合，得到磨砂效果；
- **边框**：由文字色向背景插值，得到层次分明的细线。

这三个角色都可以单独改成手动颜色：取消勾选该角色的「自动」，选一个色值即可，其余角色仍走自动推导。

如果视频是跨域的（画布被浏览器污染），采样会失败，插件退回手动指定的主题色，背景和界面配色照常工作。

## 背景音频是怎么工作的

浏览器（Chromium）规定：**用户与页面交互之前，不允许带声音的媒体自动播放**。开屏/背景恰好发生在交互之前，所以直接放带声音的媒体会被拒绝。

插件的做法：

1. 按设置的音源（视频原声或自定义音频）**先尝试带声音播放**；
2. 被拒绝时画面照常播放（改为静音重试），声音元素静音待命，右下角的音频按钮会高亮；
3. 用户**第一次点击 / 按键**，或直接点那个音频按钮，就解除静音、从头播放声音；
4. 音频按钮平时可以暂停/继续。

选「自定义音频」时，视频自带的音轨会被静音，避免两个声音叠在一起。若自定义文件无效（路径不存在、格式不支持），音源自动退回视频原声，设置页会给出提示。

## 支持的格式

视频：`mp4`、`m4v`、`webm`、`mov`、`mkv`、`ogv`、`ogm`、`mpg`、`mpeg`、`ts`

动图/静态图：`gif`、`apng`、`webp`、`avif`、`png`、`jpg`、`jpeg`、`svg`、`bmp`、`ico`

音频：`mp3`、`wav`、`ogg`、`oga`、`opus`、`m4a`、`aac`、`flac`、`weba`

**推荐 `webm`(VP9) 或 `mp4`(H.264)**，跨平台都能播。

`mov` 和 `mkv` 只是容器，能否播放取决于内部编码。转码命令：

```bash
ffmpeg -i input.mov -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart bg.mp4
ffmpeg -i input.mov -c:v libvpx-vp9 -crf 32 -b:v 0 bg.webm
```

## 常见问题

**背景看不到视频**

插件会把界面的底色改成透明以便视频透出。如果视频没有显示，检查设置页是否显示问题（例如路径无效），或确认视频格式受支持。

**背景挡住了点击**

不会。背景层是 `pointer-events: none` 且位于界面之下。如果确实遇到，多半是别的插件在开屏期间接管了输入。

**界面变透明后文字看不清**

调高 `dim`（整体压暗）或给某个区域调高 `strength`（例如底部遮罩），也可以提高消息卡片自身的对比度。

**有画面但没声音**

Chromium 要求先与页面交互才允许带声音的自动播放。确认设置里音源不是「静音」，然后在开屏画面上点一下、按任意键，或点右下角高亮的音频按钮，声音就会响起。如果浏览器本身就允许带声音自动播放，则无需操作。

**选了自定义音频但没起作用**

看设置页是否出现「当前音源不可用」的提示：自定义文件无效（不存在、格式不支持）时，插件会自动退回视频原声。GIF 等动图素材没有音轨，退回之后也就没有声音——这种情况请选一个真正的音频文件。

**仅聊天区域模式下，切到别的页面（插件、自动化任务等）会怎样**

背景视频只在有会话栏的页面出现。找不到聊天栏时（v0.8.2 起）插件**不再把背景掏满全屏**——整页保持不透明、内容不会被视频垫底，同时侧栏等区域继续跟随派生主题；回到会话页后聊天区的视频背景自动恢复。

**界面配色自动适配和 DSH 自带主题冲突吗**

不冲突。插件只在自己的作用域内用内联样式覆盖主题变量（全屏 = shell 框架；仅聊天 = 会话栏用聊天配色、框架用其余区域的派生配色），离开作用域或卸载插件时全部还原。深色/浅色切换、主题设置本身都不受影响。设置弹窗、下拉菜单等不透明浮层始终豁免，保持宿主原样。

**自动主题色不生效**

确认「自动主题色」已勾选，且视频不是跨域的（跨域画布会被浏览器污染，采样会静默失败）。

**点「选择文件…」没有反应**

对话框在运行 DSH 的机器上弹出，如果你是从另一台机器访问浏览器界面就看不到它，直接手输路径即可。

## 开发与自测

插件没有构建步骤，宿主半和浏览器半都是手写的 ES module。仓库自带两个自测脚本，不需要 Electron 或网络：

```bash
node tools/verify-contract.mjs   # 宿主半：配置归一化、媒体解析、路由、Range、状态文件
node tools/verify-client.mjs     # 浏览器半：模块注册、挂载决策、区域/主题策略
npm run verify                   # 两个一起跑
```
